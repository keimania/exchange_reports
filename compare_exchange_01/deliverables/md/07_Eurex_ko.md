# Eurex (유렉스 거래소) — 거래소 보고서

---

## 1. 거래소 개요

**정식 법인명**: Eurex Frankfurt AG / Eurex Zürich AG
**국가**: 독일 / 스위스 | **설립연도**: 1998년 (DTB + SOFFEX 합병) [WEB:wikipedia]
**모기관**: Deutsche Börse AG [WEB:wikipedia]

**시장 모델**: 경매 + 연속매매 혼합형; 파생상품 중심, T7 플랫폼 Xetra(현물)와 공유 [REF:#4]

**거래 자산**: 주가지수·개별주식·금리·배당·변동성·ETF·FX·상품·암호화폐 파생상품; Eurex Repo [WEB:eurex.com]

**매매시간 (CET)**: 시스템 01:00; 정규 매매 08:00–22:00 (상품별 상이) [WEB:eurex.com/trading-hours]

**주요 통계**: 세계 최대 파생상품 거래소 중 하나; 2,000+ 상장 파생상품 계약 [WEB:wikipedia]

---

## 2. 제도적 철학

- 1998년 탄생부터 전자 거래소 — 물리적 플로어 경험 없음
- T7 플랫폼을 Xetra(현물), EEX(에너지), Nodal Exchange와 공유 — 고유 이중용도 아키텍처
- 파생상품 특성상 시장조성자 프로그램이 핵심 (옵션 유동성 의존)
- 사전거래위험관리(Pre-trade Risk Controls) 강조 [REF:#7]

## 3–4. 주문유형

| 유형 | 설명 |
|---|---|
| 지정가 (Limit) | GFD/GTC/GTD/IOC 지원 [REF:#1] |
| 시장가 (Market) | 최적가 체결; 전략 주문 미지원 [REF:#1] |
| 시장가-지정가 전환 (Market-to-Limit) | 잔량 지정가 전환 [REF:#1] |
| 스톱 / 스톱 지정가 | 트리거 시 시장가/지정가 전환 [REF:#1] |
| 양자택일 (OCO) | 지정가 + 스톱 단일 ID 관리 [REF:#1] |
| 빙산 (Iceberg) | 부분 표시; 잔량 숨김 [REF:#1] |
| 게시전용 (Book-or-Cancel, BOC) | 즉시 체결 가능 시 거부 — 수동적 유동성만 [REF:#1] |
| 개장경매/폐장경매/경매전용 주문 | 각 경매 상태에서만 활성 [REF:#1] |

**거래소 고유**: OCO 단일 ID, BOC 게시전용, 전략 주문(다리 원자적 체결), 거래량 발견 주문

## 5–6. 매칭엔진 및 가격 발견

### T7 시스템 [REF:#4] [WEB:eurex.com/insights]
- **지연시간**: 최소 반응 시간 ~2,787 ns; EOBI 시장데이터 ETI 응답 대비 중위 1.5μs 빠름
- **처리량**: 코어 ~8,000 kHz; 참가자 레벨 ~300–500 kHz
- **인프라**: Colo 2.0 (2025년 업그레이드); 나노초 타임스탬프
- **인터페이스**: ETI (세션 기반 TCP/IP) [REF:#5]

### 매칭: 가격·시간 우선원칙; 일부 옵션 비례배분(pro-rata) [REF:#1]

### 경매: 사전매매 → 개장경매(축적→동결→체결) → 연속매매 → 폐장경매 → 사후매매
### 변동성 중단: 체결가 이탈 시 변동성 경매 자동 전환 [WEB:eurex.com/vi]

---

## 7. 안전장치

- **변동성 중단**: 단기/장기 창 가격 이탈 시 변동성 경매 전환 (상품별 매개변수)
- **사전거래위험관리**: 최대 주문수량/금액, 가격합리성, 델타등가 통제, 메시지 스로틀링, 킬스위치
- **시장 전체 서킷브레이커 없음**: 상품별 변동성 중단으로 대체

## 8. 특별 세션
