TSE / JPX (도쿄증권거래소) — 거래소 보고서

1. 거래소 개요

정식 법인명: 주식회사 도쿄증권거래소 (Tokyo Stock Exchange, Inc.) 국가: 일본 설립연도: 1878년 (원래); 1949년 재설립; 2013년 JPX 합병 [W] 모기관: Japan Exchange Group, Inc. (JPX) — 2013년 TSE와 OSE 합병으로 설립 [W]

시장 모델: 순수 주문주도형 — 이타요세(판기매, Call Auction) + 자라바(연속매매) 이중 메커니즘 [2]

거래 자산 유형: [1] - 주식 (프라임, 스탠다드, 그로스, TOKYO PRO 시장) - ETF, ETN, REIT, 인프라 펀드 - 파생상품 (OSE 경유 — 닛케이225 선물/옵션, TOPIX 선물, JGB 선물)

정규 매매시간 (JST, UTC+9): [1] - 전장: 09:00–11:30 | 점심 휴장: 11:30–12:30 - 후장: 12:30–15:25 (자라바) | 종가매매세션(CAS): 15:25–15:30 (신규)

주요 통계: [W] [W] - 상장기업 수: 약 3,945개 (프라임 1,599, 스탠다드 1,569, 그로스 614, PRO 163) - 연간 매매대금(2025): ¥1,419.6조 (프라임 국내보통주 사상 최고) [W]

최근 주요 변경사항: [W] - 2024.11.05: arrowhead 4.0 출범, 매매시간 30분 연장, 종가매매세션(CAS) 도입 - 2022.04: 시장 구조 개편 (1부/2부/마더스/JASDAQ → 프라임/스탠다드/그로스)

2. 제도적 철학

기본 시장 모델: 순수 주문주도형, 이중 경매 메커니즘 [2] - 이타요세(板寄せ): 개장/폐장/거래중단 후 재개 시 단일가 결정에 사용 - 자라바(ザラバ): 장중 연속매매에 사용 - 일반 주식에 대한 지정 시장조성자 없음 [1]

발전 과정: 물리적 플로어(1878) → 전자화(1999) → arrowhead 1.0(2010) → 2.0(2015) → 3.0(2019) → 4.0(2024.11) [W]

3. 주문유형 — 기본

3.1 지정가 주문 (指値注文, Limit Order) [2]

  • 가격, 수량, 방향 지정; 미체결 시 주문장에 등록
  • 유효기간: 당일 유효 (기본)

3.2 시장가 주문 (成行注文, Market Order) [2]

  • 가격 미지정; 이타요세 시 가격제한폭 내 의향가로 취급
  • 자라바 시 가용 가격으로 순차 체결

5. 주문유형 — 거래소 고유

5.1 후나리 주문 (引成注文, Funari Order) [2]

  • TSE 고유: 자라바 중 지정가 → 종가 이타요세/CAS 시 시장가로 자동 전환
  • KRX 조건부지정가호가와 유사 개념
  • 장중 지정가 규율과 종가 참여를 결합

5.2 특별기배 (特別気配, Tokubetsu Kehai / Special Quote) [W]

  • TSE 고유 메커니즘: 주문 불균형 시 시스템 생성 참고 호가
  • 점진적 가격 이동으로 상대방 주문 유인 — "서행 경매"
  • 경성 매매정지(hard halt)의 대안 — 가격 발견을 중단하지 않고 감속

7. 안전장치 메커니즘

7.1 가격제한폭 (値幅制限) [4]

  • 기준가(전일종가) 수준별 절대 엔화 금액 제한 (비율제가 아닌 금액제)
  • 예: 기준가 ¥1,000–1,499 → ±¥300 [W]
  • 개별 종목 연속 상/하한 도달 시 확대 가능

7.2 특별기배 (Tokubetsu Kehai) [W]

  • 주문 불균형 시 참고 호가 발행 → 점진적 가격 이동으로 주문 유인
  • TSE 고유 "연성 서킷브레이커" — 매매중단 아닌 감속

7.3 서킷브레이커 (파생상품) [W]

  • 닛케이225/TOPIX 선물: ~8% 하락 시 10분 정지
  • 주식은 시장 전체 서킷브레이커 없음 — 가격제한폭 + 특별기배로 대체

9. 유동성공급자 / 시장조성자 의무

9.1 ETF 시장조성 인센티브 제도 [W]

  • 2018.07 도입; ETF 종목 대상 지정 시장조성자
  • 최소 5개 ETF 호가, 연속경매 시간의 80% 이상 호가 유지
  • 수수료 환급/인센티브 구조; 분기별 실적 평가

9.2 일반 주식 시장조성자

  • TSE는 일반 주식에 대한 의무적 시장조성자 프로그램 없음
  • NYSE DMM, NASDAQ MM, KRX LP/MM과 대조적
  • 유동성은 전적으로 자연 주문 흐름에 의존
