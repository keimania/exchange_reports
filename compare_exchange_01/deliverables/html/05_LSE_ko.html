LSE (런던증권거래소) — 거래소 보고서

1. 거래소 개요

정식 법인명: London Stock Exchange plc (런던증권거래소) 국가: 영국 설립연도: 1801년 (공식); 1698년 조나단 커피하우스에서 거래 시작 [W] 모기관: London Stock Exchange Group (LSEG) [W]

시장 모델: 3단계 시스템 — 주문주도형(SETS), 혼합형(SETSqx), 호가주도형(SEAQ) [3] [4]

거래 자산 유형: [W] - 주식 (Main Market, AIM) - ETF, ETP, 채권, GDR - 파생상품 (LSEG 자회사 거래소 경유) - 국제주문장(IOB — 예탁증서)

정규 매매시간 (GMT/BST): [W] - 사전 매매: 05:05–07:50 - 개장 경매: 07:50–08:00 (08:00에 체결) - 연속 매매: 08:00–16:30 - 폐장 경매: 16:30–16:35 - 사후 매매: 16:40–17:15

주요 통계: [W] [W] - 상장기업 수: 약 1,900개 이상 (60개국 이상) - 시가총액: 약 £4.5조 / 약 $5.9조 (2025년 4월) - FTSE 100: 2026년 초 10,000포인트 최초 돌파

2. 제도적 철학

기본 시장 모델: 유동성 기반 3단계 분류 시스템 [3] [4]

SETS (주식전자거래서비스): [1] - 최고 유동성 종목용 순수 전자 주문장 - FTSE 100, FTSE 250, FTSE SmallCap, 유동성 높은 AIM 종목, ETF - 연속 주문주도형 매매 + 개장/폐장 경매

SETSqx (호가+교차 매매): [3] [W] - 중간 유동성 종목용 혼합형 시스템 - 일 4회 정기 경매 + 시장조성자 연속 호가 - 기명 주문(Named Order): 비익명 지정가 주문 (LSE 고유)

SEAQ (주식자동호가시스템): [3] - 최저 유동성 종목용 순수 호가주도형 시스템 - 종목당 최소 2명의 시장조성자 필수 - 전자 주문장 없음 — 시장조성자 호가로만 거래

발전 과정: 커피하우스(1698) → 물리적 플로어 → SEAQ 전자 호가(1986 빅뱅) → SETS 주문장(1997) → SETSqx 혼합형(2007) → Millennium Exchange(2011) [W]

3. 주문유형 — 기본

3.1 지정가 주문 (Limit Order) [1]

  • 최대 매수가 / 최소 매도가 지정
  • 유효기간: Day(기본), GTC, IOC, FOK, GTD
  • SETS 및 SETSqx(경매 시) 사용 가능

3.2 시장가 주문 (Market Order) [1]

  • 최적 가용 가격으로 체결
  • 부분 체결 시 잔량은 마지막 체결가의 지정가로 전환

3.3 최우선가 주문 (At Best Order) [1]

  • LSE 고유: 단일 최우선가에서만 체결; 미체결 잔량 취소
  • 복수 가격 단계 관통 방지

4. 주문유형 — 고급

4.1 빙산 주문 (Random Peak Size Iceberg) [1]

  • 표시 수량을 지정 최소~최대 범위 내 무작위 설정
  • 알고리즘 패턴 감지 방지 (LSE 강화 기능)

4.2 비표시 주문 (Hidden Order) [1] [W]

  • 완전 비표시; MiFID 증권은 대규모거래(LIS) 임계값 초과 필수

4.3 중간가 페그 주문 (Mid-Price Pegged Order) [1]

  • NBBO 중간가에 연동; 비표시
  • 선택적 최소 체결 수량 및 자동 대기(parking) 기능

4.4 스톱 / 스톱 지정가 주문 [1]

4.5 유효기간: Day, GTC, IOC, FOK, GTD — GTC/GTD 지원 (KRX/TSE와 차별) [1]

5. 주문유형 — 거래소 고유

5.1 기명 주문 (Named Order, SETSqx) [3]

  • LSE 고유: 비익명 지정가 주문 — 상대방 신원 공개
  • SETSqx 플랫폼에서만 사용 가능
  • 설계 근거: 저유동성 시장에서 상대방 신원 파악이 주문 품질 평가와 양자 협상 촉진

5.2 최우선가 주문 (At Best Order) [1]

  • LSE 고유: 단일 최우선가에서만 체결, 잔량 취소
  • 다단계 체결 방지 보호 기능

5.3 체결 가능 호가 (Executable Quote, SETSqx/SEAQ) [3]

  • 시장조성자 확정 호가 — 요청 시 즉시 체결 가능

5.4 무작위 피크 빙산 주문 [1]

  • LSE 강화: 피크 표시 수량 최소~최대 범위 내 무작위화

6. 매칭엔진 및 가격 발견

매매시스템: Millennium Exchange [W]

  • 출범: 2011년 (TradElect 대체)
  • 개발: MillenniumIT (LSEG 자회사, 스리랑카)
  • 지연시간: 평균 126μs (네이티브 API); 196μs (FIX 5.0)
  • 아키텍처: 다중시장, 다중자산 플랫폼

매칭 알고리즘 (SETS): 가격·시간 우선원칙 [1]

개장 경매 (07:50–08:00): 주문 축적 → 08:00 단일가 체결

폐장 경매 (16:30–16:35): 16:35 단일가 체결

SETSqx 경매: 일 4회 (~08:00, 11:00, 14:30, 16:35)

장중 경매 (~12:00–12:02): SETS 정오 가격 발견

호가단위: MiFID II 조화 호가단위표 (RTS 11) — 가격 + 유동성 등급별 결정

매매수량단위: 1주 (최소 거래단위 없음)

7. 안전장치 메커니즘

7.1 동적 서킷브레이커 [W]

  • 발동: 잠정 체결가가 직전 주문장 체결가 대비 3% 초과 이탈 (FTSE 100)
  • 조치: 5분간 단일가 경매

7.2 정적 서킷브레이커 [W]

  • 발동: 잠정 체결가가 직전 경매 가격 대비 8% 초과 이탈 (FTSE 100)
  • 조치: 5분간 단일가 경매; 정적 임계값 재설정

7.3 시장 전체 서킷브레이커 없음

  • 영국은 미국식 시장 전체 정지(S&P 500 7%/13%/20%) 없음
  • 개별 종목 서킷브레이커만 적용; FCA가 시장 건전성 감독
