# 10. 유럽 주요 거래소 — Deutsche Börse / Eurex & Euronext

## 1. 개요

유럽 자본시장은 Deutsche Börse Group(독일거래소그룹)과 Euronext(유로넥스트)라는 두 대형 거래소 그룹이 주도하고 있다. Deutsche Börse는 Xetra 현물 거래 플랫폼과 Eurex 파생상품 거래소를 운영하며, Euronext는 파리, 암스테르담, 브뤼셀, 리스본, 더블린, 오슬로, 밀라노 등 8개국 거래소를 통합 운영하는 범유럽 거래소이다. 2025년 기준 글로벌 24시간 거래 논의가 본격화되면서, 유럽 거래소들도 변화의 기로에 서 있다.

### 2.3 T7 매칭 엔진

#### T7 기술 사양

| 항목 | 상세 |
|------|------|
| 정식 명칭 | T7 Trading Architecture |
| 특징 | 저지연(Low Latency), 고처리량(High Throughput), 유연성 |
| 적용 거래소 | Xetra, Börse Frankfurt, Eurex, EEX, 봄베이증권거래소(BSE) 등 |
| 최신 버전 | **T7 Release 14.0** (2025년 11월 10일 도입) |
| 프로토콜 | FIX, ETI (Enhanced Trading Interface) |

T7은 Deutsche Börse Group이 개발한 차세대 거래 기술로, 낮은 지연시간과 높은 처리량, 그리고 참가자들의 유연한 활용을 지원한다. Xetra뿐 아니라 Eurex, EEX, 그리고 인도 봄베이증권거래소(BSE) 등에서도 사용되는 글로벌 표준 플랫폼이다.

### 3.4 Optiq 매칭 엔진

#### 기술 사양

| 항목 | 상세 |
|------|------|
| 명칭 | **Optiq®** |
| 유형 | 이벤트 드리븐(Event-driven) 거래 플랫폼 |
| 지연시간 | **평균 15 마이크로초** (주문 왕복) |
| 용량 | 기존 대비 **10배 증가** |
| 적용 범위 | 현물(Cash) + 파생상품(Derivatives) 단일 플랫폼 |
| 프로토콜 | 업계 표준 프로토콜 (최소 온보딩 시간) |
| 데이터 인프라 | Confluent Platform (Apache Kafka) 기반 |
| 안정성 | 24/5 무중단 운영, 가동 이후 주요 장애 없음 |
| 특징 | 최소 지터(jitter)로 알고리즘 트레이딩 최적화 |

#### Optiq 구성 요소

| 구성 요소 | 설명 |
|----------|------|
| OEG (Order Entry Gateway) | 주문 입력 게이트웨이 |
| ME (Matching Engine) | 매칭 엔진 |
| MDG (Market Data Gateway) | 시장 데이터 게이트웨이 |
| RiskGuard | 파생상품용 리스크 관리 (FIX 5.0 API + 웹 GUI) |

Optiq는 Euronext가 자체 개발한 차세대 거래 플랫폼으로, 현물과 파생상품을 하나의 플랫폼에서 처리한다. Apache Kafka 기반의 데이터 영속성 계층을 사용하여 높은 안정성과 성능을 달성했다.

## 4. 유럽 거래 시간 연장 논의

### 4.1 논의 배경

2025년 하반기부터 유럽 거래소들 사이에서 거래 시간 연장 및 24시간 거래에 대한 논의가 본격화되었다. 이는 미국에서 Cboe가 주 5일 24시간 거래를 추진하고, NYSE가 22시간 거래를, Nasdaq이 24시간 거래를 검토하는 것에 자극받은 것이다.

### 4.2 주요 거래소별 입장

| 거래소/기관 | 입장 | 상세 |
|-----------|------|------|
| **LSEG (London Stock Exchange)** | **적극 검토** | 24시간 거래 플랫폼 기술적/규제적 함의 검토 중 |
| **Cboe Europe** | **주시 중** | 리테일 투자자 참여 확대를 위해 18개 유럽 시장 수수료 인하 |
| **SIX Group (스위스)** | **부분 검토** | ETF, 파생상품 등 구조화상품의 시간 연장 검토 |
| **Euronext** | **현재 수요 없음** | 고객으로부터 시간 연장 요구가 없다며 즉각적 조치 불필요 입장 |
| **Deutsche Börse** | **수요 시 확장 가능** | 현재 수요가 없으나 수요 발생 시 확장 의향 |
| **FESE (유럽증권거래소연맹)** | **원칙 제시** | 시장 중심 유연성, 운영 준비성, 범유럽 접근 권고 |

### 4.3 주요 논점

#### 찬성 측 논거

| 논거 | 상세 |
|------|------|
| 리테일 투자자 수요 | 미국에서 장외 시간 거래가 급증하는 추세 반영 필요 |
| 글로벌 경쟁력 | 미국 거래소 시간 연장에 뒤처지면 유럽 시장 경쟁력 하락 |
| 암호화폐 경쟁 | 24/7 거래되는 암호화폐 시장에 대응 필요 |

#### 반대/우려 측 논거

| 논거 | 상세 |
|------|------|
| 유동성 분산 | 장외 시간대의 낮은 거래량으로 급격한 가격 변동 우려 |
| 미국 주식 선호 | 유럽 투자자들이 시간외에 거래하고 싶은 것은 유럽 주식이 아니라 미국 주식 |

| 기관 투자자 우려 | 종가 기반 펀드 가치 산정의 복잡성 |
| 마진콜 리스크 | 저유동성 시간대의 급격한 포지션 변동 |

### 4.4 FESE의 원칙적 입장

유럽증권거래소연맹(FESE)은 다음과 같은 원칙을 제시했다:
- 거래소가 거래 시간에 대한 결정권을 유지해야 함
- 현지 및 국경 간 투자자의 수요를 반영해야 함
- 유럽의 다양한 시장 특성을 존중해야 함
- 시장 중심의 유연성과 증거 기반의 접근법이 필요

### 4.5 Deutsche Börse의 선제적 대응

Deutsche Börse는 이미 2025년 12월부터 Extended Xetra Retail Service를 통해 거래 시간을 08:00~22:00 CET (14시간)로 확대했다. 이는 유럽 주요 거래소 중 가장 적극적인 시간 연장 조치이다.

### 6.4 시사점

1. **범유럽 통합 모델의 교훈**: Euronext가 8개국 거래소를 Optiq 단일 플랫폼으로 통합 운영하는 것은 아시아 지역의 거래소 통합 논의에 시사점을 제공한다. KRX도 ASEAN+3 등 역내 거래소 간 연결을 강화할 수 있다.

2. **리테일 시간 연장 모델**: Deutsche Börse의 Extended Xetra Retail Service(08:00~22:00)는 기관 거래와 리테일 거래의 시간을 분리하는 모델로, KRX/Nextrade의 시간외 거래 설계에 참고할 수 있다.

3. **T+1 동시 전환**: 영국/EU/스위스의 2027년 10월 T+1 동시 전환은 글로벌 정합성의 중요성을 보여준다. 한국도 글로벌 결제 주기 단축에 맞춰 T+1 전환 계획을 수립해야 한다.

4. **파생상품 시간의 전략적 중요성**: Eurex가 22:00 CET까지 파생상품 거래를 운영하는 것은 미국 시장과의 시간대 중첩을 통한 글로벌 투자자 유치 전략이다. KRX도 KOSPI 파생상품의 야간 세션 확대를 가속화해야 한다.

5. **데이터/기술 수출**: Deutsche Börse의 T7이 인도 BSE에 판매된 것처럼, 거래 기술의 글로벌 수출은 중요한 수익원이 된다. KRX의 EXTURE 3.0 시스템도 신흥국 거래소에 대한 기술 수출을 검토할 수 있다.

6. **24시간 거래의 현실적 한계**: Euronext와 Deutsche Börse의 신중한 태도는 유럽에서 24시간 거래에 대한 실질적 수요가 아직 충분하지 않음을 시사한다. KRX도 시간 연장의 속도와 범위를 실질적 수요에 기반하여 결정해야 한다.
