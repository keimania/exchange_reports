## Key Notes

### Itayose (板寄せ, Call Auction)
- 시가/종가 결정에 사용
- 거래량 최대화, 미체결 잔량 최소화 원칙으로 단일가격 결정
- 가격우선·시간우선 원칙 적용

### Zaraba (ザラバ, Continuous Trading)
- 장중 연속매매에 사용
- 최저 매도호가와 최고 매수호가가 일치할 때 체결
- 가격우선·시간우선 원칙 적용

### arrowhead 4.0 (2024.11 가동)
- 4세대 시스템 (초대 2010년 가동 이후)
- 매매시간 연장, 종가매매세션(Closing Auction Session) 도입
- 글로벌 최고 수준의 저지연·고신뢰·확장성
